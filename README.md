# RumaMap

**Sistem Informasi Jual Beli Perumahan Berbasis Geographic Information System (GIS)**

RumaMap merupakan aplikasi berbasis web untuk membantu masyarakat mencari, melihat, dan memperoleh informasi properti berdasarkan lokasi geografis.

## Teknologi

- Next.js
- React
- JavaScript
- PostgreSQL
- Prisma ORM
- Tailwind CSS
- Leaflet.js

## Fitur Utama

- Peta persebaran properti.
- Katalog dan pencarian properti.
- Filter lokasi, harga, luas, dan tipe.
- Detail properti dan galeri foto.
- Favorit dan pengajuan kunjungan.
- Dashboard Pembeli, Penjual/Agen, dan Admin.
- Verifikasi listing properti.
- Web Push Notification.

## Menjalankan Project

Pastikan Node.js sudah terpasang.

Install dependencies:

```bash
npm install
```

Jalankan development server:

```bash
npm run dev
```

Buka browser:

http://localhost:3000
